# Artifacts: Audit (`artifacts/audit/`)

Thư mục lưu trữ nhật ký đối chiếu, biên bản audit thuật toán, và kiểm tra tính toàn vẹn của pipeline phân tích video và dự báo giao thông.
Ví dụ: biên bản đối chiếu kết quả suy luận video giữa các tần số lấy mẫu (FPS), tính toán chỉ số hysteresis và độ trễ chuyển trạng thái.

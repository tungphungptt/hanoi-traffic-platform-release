Local · CPU

Đặt `FORECAST_PROVIDER=local_onnx` và để file mô hình trong `artifacts/current/`.

Dịch vụ dự báo qua API

Đặt `FORECAST_PROVIDER=remote_http`; cấu hình URL và API key trong file `.env` cạnh server.

API key không hiển thị trong trình duyệt. API từ xa bắt buộc HTTPS; HTTP chỉ được phép với localhost khi phát triển. Nếu provider lỗi, hệ thống báo lỗi thay vì giả vờ dùng kết quả dự báo thật.

Nếu đoạn A có nguy cơ tắc, đi theo hướng nào?

Hệ thống lấy hình học tuyến đường thật từ dịch vụ chỉ đường OSRM/OpenStreetMap. Nếu chưa có telemetry RTSP mới, việc chọn tuyến chỉ dựa trên thời gian mạng lưới tham chiếu — không được diễn giải là tuyến ít tắc hơn theo thời gian thực.
